How GMRC / Values Education grading would work

This is a standalone demonstration, not a working Academix page. GMRC is the elementary subject; Values Education is the junior high subject. Both use the same domain breakdown for Grades 4–10.

Step 1 · Teacher creates a score item

Tell Academix what the activity measures

For Written/Oral Works and Performance Tasks, the teacher selects a domain. This is how the system knows which part of the grade receives the score.

Example: A reflection journal can measure the affective domain. An observed action can measure the behavioral domain. An examination uses its existing test or term-exam part instead of a domain choice.

Step 3 · Academix calculates and publishes

Where each score goes

After a complete term grade is published, SF9 can copy that published grade into the subject’s term cell. It then calculates the subject’s final grade from the three published term grades. This demo shows the initial grade only; the real 2026–27 flow also applies DepEd’s adjusted transmutation table before publication.
